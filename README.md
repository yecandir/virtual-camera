# Sanal Kamera

Chrome uzantısı: kamera yerine video oynat veya MacBook kamerasını kullan. Kamera kaydı alıp onu sanal kamera olarak kullanabilirsin.

## Kurulum
1. `chrome://extensions` → **Developer mode** aç
2. **Load unpacked** → bu klasörü seç
3. Meet vb. sekmeyi bir kez yenile; sonrasında popup'tan kaynak canlı değişir.
